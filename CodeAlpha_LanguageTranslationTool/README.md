# CodeAlpha Language Translation Tool

## 📌 Project Description

A simple web-based Language Translation Tool developed as part of the CodeAlpha Artificial Intelligence Internship.

The application allows users to enter text, select a source language and target language, and translate the text using a translation API.

## ✨ Features

- Enter text for translation
- Select source language
- Select target language
- Translate text using an API
- Display translated text
- Copy translated text
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- MyMemory Translation API

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `CodeAlpha_LanguageTranslationTool` folder.
3. Open `index.html` in a web browser.
4. Enter the text you want to translate.
5. Select the source and target languages.
6. Click the **Translate** button.
