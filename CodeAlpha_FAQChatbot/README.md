# CodeAlpha FAQ Chatbot

## 📌 Project Description

A simple web-based FAQ Chatbot developed as part of the CodeAlpha Artificial Intelligence Internship.

The chatbot provides answers to frequently asked questions using predefined FAQ data and keyword-based matching.

## ✨ Features

- Interactive chatbot interface
- User can type questions
- Predefined FAQ questions
- Quick question buttons
- Keyword-based question matching
- Instant chatbot responses
- Enter key support
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `CodeAlpha_FAQChatbot` folder.
3. Open `index.html` in a web browser.
4. Type a question in the chat box.
5. Click **Send** or press Enter.
6. You can also use the Quick Questions buttons.
